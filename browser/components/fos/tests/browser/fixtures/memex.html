1945 · Atlantic Monthly

As We May Think

Vannevar Bush describes a desk-sized machine that stores a library and, more importantly, the paths a reader takes through it.

The device Bush called a memex was never built, but the argument for it has not aged. Filing is alphabetical or numerical, and the mind is neither: it snaps from one item to the next by association. A memex would record those associations directly, so that a path assembled once could be recalled, named, and handed to somebody else.

Wholly new forms of encyclopedias will appear, ready-made with a mesh of associative trails running through them, ready to be dropped into the memex and there amplified.

What was actually shipped

Almost none of it. The web inherited the link and dropped the trail: a browser records where you have been as a list with the branches thrown away, and a bookmark is a single point with no path attached to it. Sixty years of interface work has largely rebuilt the filing cabinet Bush was arguing against.
